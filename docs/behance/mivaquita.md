# Mi Vaquita — Diseño de interfaz y desarrollo de una app de gastos compartidos

Mi Vaquita parte de una situación cotidiana: salir con amigos, repartir los pagos y después intentar recordar cuánto puso cada persona.

Diseñé la interfaz y desarrollé la aplicación para reunir esa información en un mismo lugar: crear un grupo, registrar los gastos y consultar quién le debe a quién.

## Un recorrido para organizarse en grupo

La interfaz conecta el acceso a la aplicación, los grupos, el registro de gastos y las cuentas. Cada parte responde a una tarea concreta para que el recorrido acompañe la organización del plan.

## Diseño y desarrollo conectados

Programé la interfaz en React y construí una API en Express y Node.js. Separé rutas, lógica y datos para poder ampliar la aplicación sin rehacer las otras partes.

**Mi rol:** diseño de interfaz y desarrollo frontend y backend.

**Tecnologías:** React, Express y Node.js.
