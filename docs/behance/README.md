## Material visual por completar

El navegador automatizado no pudo verificar la política de acceso durante esta sesión. No se pudieron capturar versiones actuales ni abrir el editor de Behance. Las capturas guardadas en `public/media/projects` son anteriores a los cambios recientes de las aplicaciones; sirven de material de archivo y no deben publicarse como capturas actuales.

Para cada caso preparar una portada de 1400 × 1050 px y módulos de 1400 px de ancho con capturas reales, sin datos personales. Exportar en PNG o JPEG. Conservar el texto importante fuera de las capturas para que sea legible.

- **Versé:** portada, catálogo, ficha de producto, carrito y una vista móvil. Paleta de noche, rosa y seda tomada de su interfaz. Composición con una pantalla principal y dos detalles; no repetir el encabezado como si fueran tres pantallas distintas.
- **Mi Vaquita:** acceso actual, grupos, detalle de gastos y cuentas, más una vista móvil. Usar datos de demostración claramente ficticios; no publicar nombres, saldos o correos de personas reales.
- **Hilos Invisibles:** portada, mapa de capítulos, una vista de collage y la nueva galería de desarrollo. Conservar borgoña, papel, oro y los recursos recortados del sitio.

Las composiciones CSS del portafolio utilizan los recursos existentes y no sustituyen esta captura pendiente. Hilos Invisibles tiene una composición editorial de sus recursos; GYG muestra una fotografía del catálogo; Venux móvil identifica expresamente la referencia de la versión web.

## Publicación y conexión

1. Abrir el perfil `https://www.behance.net/tatianajaramil11` y comprobar los proyectos existentes para actualizar el correspondiente sin duplicarlo.
2. Cargar el texto del caso y las composiciones actuales. Revisar legibilidad y créditos.
3. Publicar y obtener el enlace real de cada caso.
4. Añadir ese enlace al campo `behanceUrl` del proyecto correspondiente. No usar el enlace genérico del perfil como si fuera un caso.
5. Ejecutar `node scripts/check-projects.mjs` y comprobar que los botones abren los casos correctos.
