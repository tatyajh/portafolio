# Paquetes listos para Behance

Cada carpeta contiene las imágenes reales y el texto listo para crear un proyecto en Behance:

- `verse`: Versé Intimates
- `mivaquita`: Mi Vaquita
- `hilos-invisibles`: Hilos Invisibles

## Cómo crear un proyecto

1. En Behance abre tu perfil y pulsa **Create a Project**.
2. Arrastra las imágenes de la carpeta `assets` en el orden indicado en el README de cada proyecto.
3. Añade los bloques de texto copiando el contenido del README.
4. En la sección de información escribe el título, las herramientas y el enlace al despliegue.
5. Guarda como borrador, revisa la vista previa y pulsa **Publish** cuando todo se vea bien.

No publiques Venux, Hoteles ni GYG como casos de diseño propio. El enlace general a tu perfil puede permanecer en tu portafolio, pero no hace falta repetirlo dentro de cada tarjeta.
