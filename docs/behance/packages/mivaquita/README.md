**Título:** Mi Vaquita — app para organizar gastos compartidos

**Descripción:** Mi Vaquita reúne grupos, gastos, fechas y aportes en un mismo lugar. Diseñé la interfaz para que organizar un paseo y saber quién debe qué fuera sencillo.

**Mi rol:** Diseño de interfaz y desarrollo frontend y backend.

**Tecnologías:** React · Express · Node.js.
